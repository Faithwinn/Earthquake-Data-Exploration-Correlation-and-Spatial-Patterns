# Earthquake-Data-Exploration-Correlation-and-Spatial-Patterns
Basic exploratory data analysis using earthquake data from the built-in R dataset quakes.
The goal of this exercise is to explore relationships between environmental variables and to understand the difference between visual and numerical measures of association. We explored the relationship between earthquake depth and magnitude using covariance and correlation.

# Dataset
The quakes dataset contains observations of 1,000 seismic events near Fiji recorded by the Harvard LASA seismograph network. Each row captures:
# Variable  Description
lat         Latitude of earthquake epicentre
long        Longitude of earthquake epicentre
depth       Depth of earthquake (km)
mag         Richter magnitude
stations    Number of stations that detected the event

# ScatterPlot
The plot shows a slight downward trend which means that deeper earthquakes tend to have marginally lower surface magnitudes. But it has substantial scatter, hinting at a weak relationship.
